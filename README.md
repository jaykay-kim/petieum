# 펫이음(PetIeum) 최종 고객용 홈페이지

고객 오픈을 가정한 펫이음 베타서비스 정적 홈페이지입니다.

## 포함 파일
- `index.html` : 메인 랜딩페이지
- `style.css` : 반응형 디자인
- `script.js` : 상세보기, 케어 조합 예시, 베타 신청 모달
- `terms.html` : 이용약관
- `privacy.html` : 개인정보 처리방침
- `refund.html` : 환불·배송정책
- `assets/` : SVG 일러스트와 로고

## GitHub/Vercel 반영 방법
1. ZIP 압축을 풉니다.
2. GitHub `petieum` 저장소에서 `Add file` → `Upload files`를 누릅니다.
3. 이 폴더 안의 파일 전체를 드래그합니다.
4. `Commit changes`를 누릅니다.
5. Vercel이 자동으로 재배포합니다.

기존 주소 `https://petieum.vercel.app`은 그대로 유지됩니다.


## 링크 미리보기 이미지

카카오톡, 네이버 밴드, 슬랙 등에서 링크 공유 시 표시되는 Open Graph 이미지가 `assets/og-image.png`로 추가되어 있습니다. 배포 후 미리보기가 이전 내용으로 보이면 카카오톡 캐시 때문에 잠시 후 다시 시도하거나, URL 뒤에 `?v=2`를 붙여 공유해 확인할 수 있습니다.
