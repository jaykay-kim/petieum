# 펫이음(PetIeum) 수정본 홈페이지

교수님 피드백 반영 버전입니다.

## 반영한 핵심 피드백
- 숫자 설계는 우수하나 사실상 커머스라 1인 운영 부담이 큼
- 보호자는 관심이 크지만 기록 자체에는 돈을 잘 내지 않음
- 제품이 실질 가치가 되어야 함
- 대형 펫몰·쿠팡과 가격 경쟁 위험
- 음성 AI 등 고비용 기능은 구독가로 감당 가능한지 계산 필요

## 수정 방향
- “AI 건강기록 앱”보다 “AI 리포트 + 맞춤 케어 제품 구독”으로 포지셔닝
- 가격 경쟁 대신 생애주기 관리, 월간 리포트, 큐레이션 가치 강조
- 초기 30명 베타, 직접배송/제휴배송 검증 흐름 추가
- 음성 AI는 초기 핵심 기능에서 제외하고 텍스트 기반 리포트 중심으로 조정
- 법적 리스크를 줄이기 위해 진단·치료·복약 변경 미제공 문구 강화

## GitHub 업로드
